## What I learned / what did not work

I learned how to structure a web page using semantic HTML elements such as
header, main, section and footer. I also learned how CSS Grid can be used for
the main two-column layout while Flexbox can be used inside forms and cards.

I learned how media queries make the interface responsive and how CSS
variables can be reused to implement a consistent dark theme. I also learned
the importance of visible keyboard focus for accessibility.

The TaskFlow example from the course could not simply be copied, so its
structure had to be adapted to the BrickStore theme and its LEGO-specific
data.
